# Taiwan county display geometry

Derived from g0v/twgeojson json/twCounty2010merge.topo.json, downloaded 2026-11-28.
Source: https://github.com/g0v/twgeojson
License: CC0 1.0 (Chia-liang Kao), https://creativecommons.org/publicdomain/zero/1.0/

22 county/city polygons, simplified for display. 桃園縣 is labeled 桃園市 after its 2014 status change; county perimeter is unchanged. 台 is normalized to 臺 for joining source results. Offshore counties use individually scaled insets, not geographic placement. This is a county overview, not a cadastral map. Paths are generated locally from the topology; no external map requests occur at runtime.
