私隱政策

更新日期：2026 年 11 月 25 日

1. 適用範圍與聯絡方式

本私隱政策說明百品導航（Baipin Navigation，以下簡稱「本站」）在提供服務時收集、使用、儲存、分享及刪除個人資料的方式，以及您管理相關資料的途徑。本站由網站維護者營運，正式網址為 https://123.baipon.com，私隱事務聯絡電郵為 root@baipin.pw。

本政策適用於本站導航、搜尋、RSS、天氣、交通、市場資訊、個人化設定、日曆及多端預設同步功能。瀏覽本站及使用基本功能毋須登入；帳戶登入、雲端同步及外部日曆連接均為可選功能。Google、Microsoft 及飛書日曆存取須另外授權，預設同步授權不會自動授予日曆存取權限。

2. 本機設定、預設備份與雲端同步

本機設定包括書籤名稱、網址、圖示及排序，自訂搜尋引擎、RSS 來源、CITY FEED 顯示項目與跑馬速度、主題、語言、背景，以及天氣和日曆顯示偏好。設定主要儲存在瀏覽器 localStorage；背景圖片網址及署名儲存在 homepage_bg Cookie，攝影機來源、鏡頭編號及自動更新偏好儲存在 localStorage。背景圖片檔案及取得時間不納入預設備份。

使用「還原預設設定」時，本站會在目前分頁的 sessionStorage 中暫存還原前的設定，以便復原操作；該暫存副本不會上傳至伺服器。還原預設設定會暫停本裝置自動同步，不刪除登入狀態或雲端預設。

啟用同步後，本站伺服器會在處理請求期間接收相關設定，並將其傳送至您選擇的 Google Drive 應用程式專用空間、GitHub Secret Gist、OneDrive 應用程式資料夾或飛書雲空間預設資料夾。iCloud／Canvas 登入憑證預設經伺服器加密後納入完整預設；各登入服務的 OAuth 權杖不納入預設備份。

統計 Cookie、同步服務選擇、自動同步開關、同步基線、精確位置、搜尋輸入歷史及即時資料快取不納入預設備份。您填寫的書籤、RSS 或搜尋引擎網址可能包含個人資料，請在匯出或同步前檢查相關內容。頁尾的上次同步時間僅儲存在本機。

自動同步須在每台裝置上分別啟用，程式每 30 秒檢查一次，並在編輯設定或開啟對話框時暫停。日曆登入狀態亦會在登入同步帳戶或主動同步時處理。如本機與雲端設定存在無法自動判斷的差異，本站將要求您選擇保留的版本。載入雲端預設可能取代相應本機設定並重新載入頁面。

JSON 匯出與雲端同步涵蓋相同的完整預設：一般設定以可讀 JSON 儲存，iCloud／Canvas 登入憑證以伺服器加密的密文儲存；這不屬於僅由使用者持有密鑰的端到端加密。本站不建立用於儲存使用者個人資料或預設的伺服器資料庫，亦不提供供維護者瀏覽使用者預設的管理介面。同步資料僅在請求期間處理，本站不另行持久儲存預設副本。匯出檔案由您自行保管。

3. Google 登入與預設同步

僅在您點擊「使用 Google 登入」並在 Google 授權頁面允許後，本站才取得以下 Google 資料。您可以拒絕或取消授權，繼續使用毋須登入的功能。

  • openid：取得 Google 帳戶唯一識別碼（sub），區分不同帳戶的同步狀態，避免將不同帳戶的預設混用。
  • email：取得帳戶電郵，在同步面板顯示目前登入的帳戶，便於您確認使用的是哪一個 Google 帳戶。本站不讀取信箱內的郵件，亦不會使用該電郵傳送行銷郵件。
  • profile：授權流程會收到 Google 基本個人資料回應。目前功能保留姓名和頭像網址，與帳戶識別碼和電郵一同用於登入狀態及頁尾頭像展示；頭像網址僅隨加密工作階段 Cookie 儲存，不寫入預設檔案或 JSON 備份。本站不要求您的生日、地址或電話號碼。
  • drive.appdata：預設同步僅在您自己的 Google Drive 應用專用空間 appDataFolder 建立、讀取、更新或刪除本站預設檔案，不申請完整 Drive 權限，不讀取其他 Drive 檔案、Gmail 或通訊錄。預設同步權限本身不包含日曆存取；另外啟用的 Google 日曆授權見下文。

OAuth 授權碼、存取權杖和更新權杖：伺服器用授權碼向 Google 換取權杖，隨後用存取權杖請求帳戶資料和應用專用預設檔案，用更新權杖在授權有效時延續同步。本站不會取得您的 Google 密碼；權杖不會進入 JSON 備份或雲端預設檔案。

4. GitHub 登入與 Secret Gist 同步

選擇 GitHub Gist 並主動登入後，本站透過 GitHub OAuth 取得您的公開帳戶 ID、使用者名稱（login）、顯示名稱和頭像網址，用於識別目前同步帳戶和顯示頁尾頭像。頭像網址僅儲存在加密工作階段 Cookie，不進入預設或 JSON 備份；瀏覽器顯示頭像時會向 GitHub 頭像服務發起圖片請求。本站不申請私人電郵、儲存庫、組織或通訊錄權限，不儲存 GitHub 電郵。拒絕授權不影響本機導航與備份功能。

GitHub 的 gist OAuth 範圍可存取帳戶下的 Gist，無法限制至單一應用程式檔案。為定位本站設定，伺服器會讀取您的 Gist 清單中繼資料，並僅讀取和更新由目前帳戶擁有、描述標記為 Baipin Navigation preset sync (v1)、包含 baipin-navigation-presets-v1.json 檔案的 Secret Gist。本站不讀取其他 Gist 的檔案內容，亦不修改無關 Gist。

Secret Gist 並非真正私有儲存，不公開列出，但知道連結的人可能讀取內容。一般書籤、RSS 及偏好為可讀 JSON；iCloud／Canvas 登入狀態部分為伺服器加密的密文。不要在一般設定文字中填寫密碼、權杖或敏感資料。登入面板會說明此限制。

選擇 GitHub 同步時，您要求本站將本機預設傳送給 GitHub，並從該 Gist 讀取預設供您還原。GitHub 按其私隱聲明和條款處理帳戶、請求與 Gist 資料。本站不向 GitHub 傳送您的 Google 身分資料或 Google OAuth 權杖，不會自動讀取 Google Drive 檔案並傳給 GitHub。各服務的工作階段、自動同步開關與版本基線按服務和帳戶分開管理，不按同名帳戶或電郵自動合併；切換後若主動同步，本機目前設定會傳送至新選擇的服務。

GitHub OAuth 使用 state 和 PKCE。帳戶資料及存取權杖（如適用，亦包括更新權杖）經 AES-256-GCM 加密，儲存在獨立的 HttpOnly、Secure、SameSite=Lax Cookie，最長有效期 30 天；存取權杖更新不延長原工作階段期限。GitHub 用戶端密鑰僅儲存在伺服器環境變數 GITHUB_KEY，不會進入前端或匯入匯出。正常請求經 HTTPS 傳輸；伺服器不建立使用者或預設資料庫、不主動記錄原始權杖或完整預設。GitHub 資料不用於廣告、出售、AI 模型訓練或 AI NCII。

登出 GitHub 同步會清除本機 GitHub 工作階段及相應自動同步開關，不影響其他服務的工作階段，不撤銷 GitHub 授權。可在本站設定清除雲端預設；僅包含本站預設檔案的 Gist 會被刪除，同一 Gist 如有其他檔案則僅移除本站預設檔案。亦可自行在 gist.github.com 管理檔案，並在 GitHub Settings → Applications → Authorized OAuth Apps 撤銷本站授權。其他裝置仍可能重新上傳；GitHub 對修訂歷史及備份的保留以其政策為準。

GitHub 資料處理、服務商存取及私隱請求適用本政策關於基礎設施、必要存取、安全與聯絡的說明。您可透過 root@baipin.pw 要求相關協助，但不要傳送 GitHub 密碼或 OAuth 權杖。

5. Microsoft 登入與 OneDrive 同步

僅在您選擇 Microsoft 並授權後，本站讀取 Microsoft Graph /me 傳回的帳戶 ID、顯示名稱和電郵或登入名稱，用於識別同步帳戶和顯示登入狀態；預設同步不讀取郵件內容、通訊錄或日曆；另行授權的日曆功能見下文。頁尾使用姓名首字作為頭像，不額外請求 Microsoft 頭像。

Microsoft 登入申請 openid、profile、email 及 User.Read 以識別帳戶，offline_access 用於更新存取權杖；Files.ReadWrite.AppFolder 用於在 OneDrive 應用程式資料夾建立、讀取、更新或刪除本站預設。本站不申請 Files.ReadWrite 或 Files.ReadWrite.All。日曆讀寫由獨立的 Calendars.ReadWrite 授權控制。工作或學校帳戶可能受組織政策、管理員同意及 OneDrive 開通情況限制。

預設包含前述可同步設定，包括世界天氣城市及貼在首頁的偏好；在您主動同步、開啟自動同步，或處理預設日曆登入狀態同步時傳至 Microsoft。Microsoft 按其私隱聲明（https://privacy.microsoft.com/privacystatement）及服務條款處理帳戶、請求與 OneDrive 檔案。各同步服務的帳戶、工作階段、版本基線及自動同步開關獨立，不自動複製、關聯或合併 Google、GitHub、Microsoft 和飛書雲端預設。

OAuth 使用 state 與 PKCE。帳戶資料和存取／更新權杖以 AES-256-GCM 加密後分段儲存在 HttpOnly、Secure、SameSite=Lax Cookie 中，最長 30 天，更新不延長原期限；用戶端密鑰僅存於伺服器環境變數。伺服器只在請求期間暫時處理同步資料，不另建個人資料或預設資料庫，不主動記錄原始權杖或完整預設。Microsoft 使用者資料不用於廣告、出售、通用 AI 模型訓練或 AI NCII。預設檔案在 OneDrive 中以可讀 JSON 儲存，不是端到端加密備份。

登出 Microsoft 僅清除此裝置的 Microsoft 工作階段及自動同步，不撤銷授權或刪除 OneDrive 預設。可在本站設定清除目前帳戶的雲端預設；亦可自行刪除：先在各裝置關閉 Microsoft 自動同步並登出，再到 OneDrive 的 Apps／應用程式資料夾中刪除本站預設；檔案、資源回收筒、歷史版本與備份的保留及刪除以 Microsoft 政策為準。個人帳戶可在 https://account.live.com/consent/Manage 撤銷授權，工作或學校帳戶透過組織提供的應用程式權限管理頁面或聯絡管理員撤銷。需要協助可聯絡 root@baipin.pw，請勿傳送密碼、密鑰或權杖。

本站在 /.well-known/microsoft-identity-association.json 發佈 Microsoft 應用程式與本站網域的公開關聯聲明，供驗證發行者身分。該聲明僅包含公開應用程式識別碼，不包含使用者身分、登入憑證或預設內容。

6. 飛書登入、雲空間同步與日曆

您選擇飛書並授權後，本站取得公開帳戶識別碼及顯示名稱，並將存取／更新權杖加密儲存在本裝置的 HttpOnly、Secure、SameSite Cookie 中，最長 30 天。同步使用 offline_access 及 drive:drive 權限；雲空間授權範圍並非應用程式私有空間，但本站僅列出目錄、定位或建立 BaipinNavigation-Presets 資料夾，並讀寫、下載或移除其中帶本站預設檔名前綴的 JSON 檔案，不調整共享權限，亦不讀取其他檔案內容。完整預設包含原有設定及已加密的 iCloud／Canvas 登入狀態。飛書 OAuth 權杖不加入預設或 JSON 備份。

日曆使用同一飛書登入工作階段，另外申請 calendar:calendar 權限後讀取可存取日曆及日程；可在本站新增、編輯及刪除有權限的一般日程。重複日程、邀請及不屬於目前使用者組織的日程請在飛書處理。顯示偏好加入預設，日程本身仍由飛書儲存。登出日曆保留預設同步登入；登出飛書同步清除此裝置的飛書工作階段。可清除本站雲端預設或在飛書帳戶的應用程式／授權管理中撤銷授權；組織管理員的應用程式發佈、可用範圍及安全政策可能限制登入、雲空間或日曆存取。

7. 日曆存取、日程處理與 iCloud

日曆為可選功能。已有 Google、Microsoft 或飛書同步帳戶會被識別，但日曆權限須另外授權；已取得的日曆授權在有效期內可繼續使用。Google 申請 calendar.calendarlist.readonly 以列出日曆、calendar.events 以讀取及寫入日程；Microsoft 申請 Calendars.ReadWrite；飛書申請 calendar:calendar。拒絕日曆授權不影響導航、本機設定或已有的預設同步權限。

本站讀取已選日曆的名稱、識別碼、可編輯狀態，以及顯示月份內的日程標題、起止日期和時間、全日狀態、地點、備註、重複日程識別碼及版本資料；為今天／明天提醒，必要時額外讀取相應日期範圍。儲存或確認刪除會寫回所選提供商，不自動跨服務複製日程。Google、Microsoft、飛書、iCloud 及 Canvas 各可連接一個帳戶，並選擇顯示的日曆或課程；具體讀寫能力取決於源服務權限，Canvas 為唯讀。

iCloud 日曆透過 CalDAV 單獨連接，不使用 Sign in with Apple。您輸入的 iCloud 帳戶和 App 專用密碼只經 HTTPS 傳至本站介面，再用於向 Apple 官方 CalDAV 服務認證。帳戶、App 專用密碼及日曆目錄經 AES-256-GCM 加密後儲存在獨立的 HttpOnly、Secure、SameSite=Lax 工作階段 Cookie 中，最長 30 天；伺服器僅在請求期間解密使用，不另建憑證資料庫，不主動記錄密碼或完整日程。App 專用密碼可能授予 Apple 所允許的日曆存取能力，不能只限於勾選顯示的日曆；請勿輸入 Apple 帳戶主密碼。Apple 按其私隱政策（https://www.apple.com/legal/privacy/）處理帳戶和日曆請求。

載入的日曆名稱及日程內容僅供目前頁面使用，不寫入 localStorage、JSON 預設備份或雲端預設。日曆顯示偏好儲存各服務的帳戶識別碼及已選日曆／課程 ID，隨完整預設匯出及同步。iCloud App 專用密碼、Canvas 權杖及相應連接資料預設由伺服器加密後，以密文儲存在本機預設、JSON 備份及所選同步服務中；Google、GitHub、Microsoft 及飛書 OAuth 權杖只儲存在本裝置加密工作階段 Cookie，不進入預設備份。頁面可見時日曆每五分鐘更新，亦可手動更新。單一事件「不再提示」的 Cookie 儲存事件識別碼摘要，有效期兩天，不含標題、內容或權杖，不匯出或同步。

在日曆帳戶對話框中登出 Google、Microsoft 或飛書日曆，只停止本裝置的日曆連接，保留該服務的預設同步工作階段，不刪除日程，亦不撤銷第三方授權。在同步設定中登出該提供商會結束本機相應同步及日曆工作階段。中斷 iCloud 或 Canvas 只清除本機日曆工作階段，不刪除已儲存在預設中的加密登入狀態；日後登入同步帳戶或主動同步可重新還原連接。清除雲端預設後自動上傳暫停；重新登入或主動同步可恢復。完全登出本站會清除本機所有同步和日曆工作階段及本機日曆密文，不代您撤銷第三方授權。可在各提供商的授權管理、https://account.apple.com/ 或學校 Canvas 設定撤銷權限及權杖；其他裝置及已匯出檔案需分別處理。

日曆資料和憑證不用於廣告、出售、建立無關個人檔案、AI NCII 或通用 AI 模型訓練，不傳送給 RSS、行情或背景內容提供商。本站不傳送日曆分析事件或把日程加入統計欄位。第三方服務、網站託管和安全提供商的必要請求處理仍適用本政策。您可透過 root@baipin.pw 查詢、停止連接或尋求刪除協助，請勿電郵傳送密碼、App 專用密碼、權杖或完整私人日曆。

8. Canvas 學校日曆與作業資料

Canvas 為可選唯讀連接。您提供學校 Canvas 的 HTTPS 網址和個人存取權杖後，本站伺服器向該學校的 Canvas API 傳送權杖，讀取目前使用者標識／顯示名稱、課程標識／名稱，以及所選課程在目前月份內的日曆和作業標題、截止日期（Due）、時間、地點、描述與原網頁連結，用於月曆和日程詳情。本站僅呼叫讀取介面，不讀取成績、提交作業或修改學校課程。個人權杖本身可能授予較廣權限，請遵守學校規定，設定適當到期日期，並僅連接您獲准存取的學校系統。

Canvas 網址、帳戶識別碼及權杖以 AES-256-GCM 加密後儲存在本裝置 HttpOnly、Secure、SameSite=Lax 工作階段 Cookie，最長 30 天；伺服器僅在請求期間解密使用，不另建權杖或課程資料庫。課程及作業內容只供目前頁面使用，不加入預設備份；帳戶識別碼及已選課程 ID 隨顯示偏好儲存。Canvas 權杖及連接資料預設由伺服器另外加密，以密文納入 localStorage、完整預設及 JSON 匯出；明文不寫入這些備份，詳見日曆登入狀態加密章節。
