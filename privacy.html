1. 應用、維護者與適用範圍

百品導航（Baipin Navigation）由本站維護者營運，正式網站為 https://123.baipon.com，私隱事務聯絡電郵為 root@baipin.pw。本政策適用於全站頁面及導航、搜尋、新聞 RSS、香港天氣與交通、市場資訊、個人化設定、備份和 Google／GitHub 多端預設同步功能。

毋須登入即可查看本站用途、隱私政策和服務條款，亦可使用導航、資訊與本機設定。Google 或 GitHub 登入僅用於你主動啟用的跨裝置預設同步，並非存取首頁或閱讀應用說明的條件。

2. Google 使用者資料：存取範圍與具體用途

僅在你點擊「使用 Google 登入」並在 Google 授權頁面允許後，本站才取得以下 Google 資料。你可以拒絕或取消授權，繼續使用毋須登入的功能。

openid：取得 Google 帳戶唯一識別碼（sub），區分不同帳戶的同步狀態，避免將不同帳戶的預設混用。

email（https://www.googleapis.com/auth/userinfo.email）：取得帳戶電郵，在同步面板顯示目前登入的帳戶，便於你確認使用的是哪一個 Google 帳戶。本站不讀取信箱內的郵件，亦不會使用該電郵傳送行銷郵件。

profile（https://www.googleapis.com/auth/userinfo.profile）：授權流程會收到 Google 基本個人資料回應。目前實作保留姓名和頭像網址，與帳戶識別碼和電郵一同用於登入狀態及頁尾頭像展示；頭像網址僅隨加密工作階段 Cookie 儲存，不寫入預設檔案或 JSON 備份。本站不要求你的生日、地址或電話號碼。

https://www.googleapis.com/auth/drive.appdata：僅在你自己的 Google Drive 應用專用空間 appDataFolder 中建立、讀取和更新本站預設檔案 baipin-navigation-presets-v1.json，使同一帳戶可以在多台裝置還原和同步首頁設定。本站不申請完整 Drive 權限，不列出或讀取你其他的 Drive 文件、照片和檔案，亦不要求 Gmail、通訊錄或日曆權限。

OAuth 授權碼、存取權杖和更新權杖：伺服器用授權碼向 Google 換取權杖，隨後用存取權杖要求帳戶資料和應用專用預設檔案，用更新權杖在授權有效時延續同步。本站不會取得你的 Google 密碼；權杖不會進入 JSON 備份或雲端預設檔案。

3. 本機設定、雲端預設與同步方式

本機設定包括：書籤名稱、網址、圖示和排序，自訂搜尋引擎及目前引擎，RSS 來源，CITY FEED 自選股票、顯示項目、RSS 子項目及跑馬速度，主題、語言、背景圖片網址和署名，雨量與 AQHI 監測地區。書籤等偏好儲存在 localStorage，背景偏好儲存在 homepage_bg Cookie。 使用還原預設設定時，本站會在目前分頁的 sessionStorage 中暫存還原前的預設以供復原，不會將此復原備份上傳至伺服器。還原會暫停本裝置自動同步，不刪除登入狀態或雲端預設。 攝影機背景的來源、鏡頭編號及自動更新偏好儲存在 localStorage，納入預設匯入匯出和同步；圖像及其取得時間不會寫入預設備份。

點擊「立即同步」或開啟本裝置目前服務的自動同步後，本站伺服器會暫時接收允許同步的本機設定，按照你選擇的服務傳送至 Google Drive 應用專用空間或 GitHub Secret Gist。雲端預設不包含 Google／GitHub 登入憑證、統計 Cookie、服務選擇、自動同步開關、同步基線、精確位置、搜尋輸入歷史或即時行情快取。你自行填入的書籤、RSS 或搜尋引擎網址可能含有私人資訊，請自行檢查設定內容。

自動同步由你在每台裝置個別開啟，每 30 秒檢查一次，在編輯或開啟設定對話框時暫停。首次發現兩端預設不同或兩端均有修改時，本站會要求你選擇版本，不在未選擇時直接覆蓋。套用雲端預設可能重新整理頁面並取代對應的本機設定。

JSON 匯出與同步使用相同的預設範圍。備份檔案以可讀文字形式儲存在你選擇的裝置位置，由你保管；它不是端對端加密備份。本站不建立使用者個人資料或預設資料庫；同步所需資料僅在請求期間由伺服器暫時處理，不另行持久儲存。本站不提供供維護者瀏覽各使用者雲端預設的管理介面。頁尾的上次同步時間是本裝置成功同步的時間，儲存在本機同步狀態中，不上傳為預設。顯示 Google 頭像時，瀏覽器會向 Google 頭像服務請求圖片。

6. 資料保護措施

正式網站使用 HTTPS 傳輸請求。Google 登入使用 OAuth state 驗證和 PKCE；預設寫入介面驗證請求來源和雲端版本，降低跨站請求偽造與並行覆蓋風險。Google 用戶端密鑰僅儲存在伺服器環境變數，不寫入前端、預設或備份。

帳戶識別碼、姓名、電郵及存取／更新權杖經 AES-256-GCM 加密後儲存在 HttpOnly、Secure、SameSite=Lax 工作階段 Cookie 中，網頁指令碼不能直接讀取該 Cookie。伺服器僅為處理同步請求解密必要資訊，不在介面錯誤回應或應用程式紀錄中主動記錄原始權杖、密鑰或完整雲端預設。Google Drive 檔案由 Google 的儲存和存取控制機制保護，本站不聲稱這些檔案經過端對端加密。

任何網絡服務均無法保證絕對安全。請保護裝置、瀏覽器和 Google 帳戶，並自行妥善保管 JSON 備份。

7. 儲存期限、登出與刪除

本機預設：保留至你清除瀏覽器中 123.baipon.com 的網站資料或以其他設定取代。homepage_bg 背景 Cookie 的最長有效期為一年。JSON 匯出檔案保留至你自行刪除；刪除網站資料不會刪除已下載的備份。

登入身分與權杖：加密工作階段 Cookie 最長有效期為 30 天，不會因背景更新存取權杖而延長原工作階段期限。點擊資料管理中的「登出」會清除此裝置的同步工作階段並關閉本裝置自動同步；刪除網站資料亦可移除該 Cookie。本站沒有另外儲存該工作階段的伺服器使用者資料庫。

撤銷 Google 授權：前往 https://myaccount.google.com/connections，在第三方連結中找到百品導航對應的應用程式並移除存取權限。撤銷後，本站不能繼續使用該授權存取你的 Google 資料，可能需要你重新登入。登出本站不等於撤銷 Google 授權。

刪除雲端預設：先在所有裝置關閉自動同步並登出本站，再前往 Google Drive 網頁「設定 → 管理應用程式」，找到本站對應的應用程式，使用「刪除隱藏的應用程式資料」選項。Google 介面名稱可能隨語言調整。刪除後無法透過本站還原，建議事先匯出備份；若再次啟用同步，本機預設可能重新上傳。

雲端檔案會儲存在你自己的 Google Drive，直至你刪除該應用程式資料或 Google 按其政策處理；撤銷授權或登出本身不會刪除檔案。Google 對歷史版本、備份和技術紀錄的保留期限由其政策及服務設定決定。本站不會在你登出後另行保留一份雲端預設副本。

如需查詢、更正、刪除相關資料或撤銷授權的協助，請向 root@baipin.pw 說明請求。維護者會在核實必要資訊後說明可處理的範圍和進度；對於你自己 Google Drive 中的檔案，通常需要你按上述步驟操作。不要傳送 Google 密碼或授權權杖。

10. GitHub 登入與 Secret Gist 同步

選擇 GitHub Gist 並主動登入後，本站透過 GitHub OAuth 取得你的公開帳戶 ID、使用者名稱（login）、顯示名稱和頭像網址，用於識別目前同步帳戶和顯示頁尾頭像。頭像網址僅儲存在加密工作階段 Cookie，不進入預設或 JSON 備份；瀏覽器顯示頭像時會向 GitHub 頭像服務發起圖片請求。本站不申請私人電郵、儲存庫、組織或通訊錄權限，不儲存 GitHub 電郵。拒絕授權不影響本機導航與備份功能。

GitHub 的 gist OAuth 範圍可存取帳戶下的 Gist，無法限制至單一應用程式檔案。為定位本站設定，伺服器會讀取你的 Gist 清單中繼資料，並僅讀取和更新由目前帳戶擁有、描述標記為 Baipin Navigation preset sync (v1)、包含 baipin-navigation-presets-v1.json 檔案的 Secret Gist。本站不讀取其他 Gist 的檔案內容，亦不修改無關 Gist。

Secret Gist 不是真正的私有儲存：它不在公開清單展示，但任何知道連結的人均可能讀取內容。預設以未加密 JSON 儲存，可能包含你的書籤、網址、RSS 和偏好；請勿放入密碼、權杖或其他敏感資訊。使用此服務前，登入面板會顯示此限制。

選擇 GitHub 同步時，你要求本站將本機預設傳送給 GitHub，並從該 Gist 讀取預設供你還原。GitHub 按其私隱聲明和條款處理帳戶、請求與 Gist 資料。本站不向 GitHub 傳送你的 Google 身分資料或 Google OAuth 權杖，不會自動讀取 Google Drive 檔案並傳給 GitHub。兩種服務的工作階段、自動同步開關與版本基線按服務和帳戶分開管理，不按同名帳戶或電郵自動合併；切換後若主動同步，本機目前設定會傳送至新選擇的服務。

GitHub OAuth 使用 state 和 PKCE。帳戶資料及存取權杖（如適用，亦包括更新權杖）經 AES-256-GCM 加密，儲存在獨立的 HttpOnly、Secure、SameSite=Lax Cookie，最長有效期 30 天；存取權杖更新不延長原工作階段期限。GitHub 用戶端密鑰僅儲存在伺服器環境變數 GITHUB_KEY，不會進入前端或匯入匯出。正常請求經 HTTPS 傳輸；伺服器不建立使用者或預設資料庫、不主動記錄原始權杖或完整預設。GitHub 資料不用於廣告、出售、AI 模型訓練或 AI NCII。

登出目前 GitHub 帳戶會清除此裝置的 GitHub 同步工作階段並關閉該帳戶在本裝置的自動同步，不影響獨立的 Google 工作階段，亦不會撤銷 GitHub 授權或刪除 Gist。撤銷權限請在 GitHub Settings → Applications → Authorized OAuth Apps 中撤銷本站應用程式。刪除雲端預設前，先在所有裝置關閉 GitHub 自動同步並登出，再到 gist.github.com 刪除對應的預設 Gist；如再次啟用同步，設定可能重新上傳。Gist 檔案、修訂歷史和備份的保留與刪除以 GitHub 政策為準。
