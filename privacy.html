百品導航（Baipin Navigation）由本站維護者營運，正式網站為 https://123.baipon.com，私隱事務聯絡電郵為 root@baipin.pw。本政策適用於全站頁面及導航、搜尋、新聞 RSS、香港天氣與交通、市場資訊、個人化設定、備份和 Google／GitHub／Microsoft 多端預設同步功能。

毋須登入即可查看本站用途、私隱政策和服務條款，亦可使用導航、資訊與本機設定。Google、GitHub 或 Microsoft 登入僅用於你主動啟用的跨裝置預設同步，並非存取首頁或閱讀應用說明的條件。

2. Google 使用者資料：存取範圍與具體用途

僅在你點擊「使用 Google 登入」並在 Google 授權頁面允許後，本站才取得以下 Google 資料。你可以拒絕或取消授權，繼續使用毋須登入的功能。

email：取得帳戶電郵，在同步面板顯示目前登入的帳戶，便於你確認使用的是哪一個 Google 帳戶。本站不讀取信箱內的郵件，亦不會使用該電郵傳送行銷郵件。

profile：授權流程會收到 Google 基本個人資料回應。目前實作保留姓名和頭像網址，與帳戶識別碼和電郵一同用於登入狀態及頁尾頭像展示；頭像網址僅隨加密工作階段 Cookie 儲存，不寫入預設檔案或 JSON 備份。本站不要求你的生日、地址或電話號碼。

drive.appdata：僅在你自己的 Google Drive 應用專用空間 appDataFolder 中建立、讀取和更新本站預設檔案 baipin-navigation-presets-v1.json，使同一帳戶可以在多台裝置還原和同步首頁設定。本站不申請完整 Drive 權限，不列出或讀取你其他的 Drive 文件、照片和檔案，預設同步亦不要求 Gmail、通訊錄或日曆權限；使用者另行啟用的日曆功能見下文。

OAuth 授權碼、存取權杖和更新權杖：伺服器用授權碼向 Google 換取權杖，隨後用存取權杖要求帳戶資料和應用專用預設檔案，用更新權杖在授權有效時延續同步。本站不會取得你的 Google 密碼；權杖不會進入 JSON 備份或雲端預設檔案。

本機設定包括：書籤名稱、網址、圖示和排序，自訂搜尋引擎及目前引擎，RSS 來源，CITY FEED 自選股票、顯示項目、RSS 子項目及跑馬速度，主題、語言、背景圖片網址和署名，雨量與 AQHI 監測地區。書籤等偏好儲存在 localStorage，背景偏好儲存在 homepage_bg Cookie。 使用還原預設設定時，本站會在目前分頁的 sessionStorage 中暫存還原前的預設以供復原，不會將此復原備份上傳至伺服器。還原會暫停本裝置自動同步，不刪除登入狀態或雲端預設。 攝影機背景的來源、鏡頭編號及自動更新偏好儲存在 localStorage，納入預設匯入匯出和同步；圖像及其取得時間不會寫入預設備份。

點擊「立即同步」或開啟本裝置目前服務的自動同步後，本站伺服器會暫時接收允許同步的本機設定，按你選擇的服務傳送至你自己的 Google Drive 應用專用空間、GitHub Secret Gist 或 OneDrive 應用程式資料夾。雲端預設不包含 Google／GitHub／Microsoft 登入憑證、統計 Cookie、服務選擇、自動同步開關、同步基線、精確位置、搜尋輸入歷史或即時行情快取。你自行填入的書籤、RSS 或搜尋引擎網址可能含有私人資訊，請自行檢查設定內容。

自動同步由你在每台裝置個別開啟，每 30 秒檢查一次，在編輯或開啟設定對話框時暫停。首次發現兩端預設不同或兩端均有修改時，本站會要求你選擇版本，不在未選擇時直接覆蓋。套用雲端預設可能重新整理頁面並取代對應的本機設定。

JSON 匯出與同步使用相同的預設範圍。備份檔案以可讀文字形式儲存在你選擇的裝置位置，由你保管；它不是端對端加密備份。本站不建立使用者個人資料或預設資料庫；同步所需資料僅在請求期間由伺服器暫時處理，不另行持久儲存。本站不提供供維護者瀏覽各使用者雲端預設的管理介面。頁尾的上次同步時間是本裝置成功同步的時間，儲存在本機同步狀態中，不上傳為預設。顯示 Google 頭像時，瀏覽器會向 Google 頭像服務請求圖片。

6. 資料保護措施

正式網站使用 HTTPS 傳輸請求。Google 登入使用 OAuth state 驗證和 PKCE；預設寫入介面驗證請求來源和雲端版本，降低跨站請求偽造與並行覆蓋風險。Google 用戶端密鑰僅儲存在伺服器環境變數，不寫入前端、預設或備份。

帳戶識別碼、姓名、電郵及存取／更新權杖經 AES-256-GCM 加密後儲存在 HttpOnly、Secure、SameSite=Lax 工作階段 Cookie 中，網頁指令碼不能直接讀取該 Cookie。伺服器僅為處理同步請求解密必要資訊，不在介面錯誤回應或應用程式紀錄中主動記錄原始權杖、密鑰或完整雲端預設。Google Drive 檔案由 Google 的儲存和存取控制機制保護，本站不聲稱這些檔案經過端對端加密。

任何網絡服務均無法保證絕對安全。請保護裝置、瀏覽器及 Google、GitHub 或 Microsoft 帳戶，並自行妥善保管 JSON 備份。

7. 儲存期限、登出與刪除

本機預設：保留至你清除瀏覽器中 123.baipon.com 的網站資料或以其他設定取代。homepage_bg 背景 Cookie 的最長有效期為一年。JSON 匯出檔案保留至你自行刪除；刪除網站資料不會刪除已下載的備份。

登入身分與權杖：各登入服務的加密工作階段 Cookie 最長有效期為 30 天，不因更新存取權杖而延長原工作階段期限。登出目前服務只清除此裝置該服務的同步工作階段及自動同步開關，不影響其他服務的獨立工作階段，不撤銷授權或刪除雲端預設。清除網站資料亦可移除本機 Cookie。本站不另建伺服器使用者資料庫；各服務的撤銷授權及雲端檔案刪除方法見對應章節。

撤銷 Google 授權：前往 https://myaccount.google.com/connections，在第三方連結中找到百品導航對應的應用程式並移除存取權限。撤銷後，本站不能繼續使用該授權存取你的 Google 資料，可能需要你重新登入。登出本站不等於撤銷 Google 授權。

刪除雲端預設：先在所有裝置關閉自動同步並登出本站，再前往 Google Drive 網頁「設定 → 管理應用程式」，找到本站對應的應用程式，使用「刪除隱藏的應用程式資料」選項。Google 介面名稱可能隨語言調整。刪除後無法透過本站還原，建議事先匯出備份；若再次啟用同步，本機預設可能重新上傳。

雲端檔案會儲存在你自己的 Google Drive，直至你刪除該應用程式資料或 Google 按其政策處理；撤銷授權或登出本身不會刪除檔案。Google 對歷史版本、備份和技術紀錄的保留期限由其政策及服務設定決定。本站不會在你登出後另行保留一份雲端預設副本。

如需查詢、更正、刪除相關資料或撤銷授權的協助，請向 root@baipin.pw 說明請求。維護者會在核實必要資訊後說明可處理的範圍和進度；對於你自己 Google Drive 中的檔案，通常需要你按上述步驟操作。不要傳送 Google 密碼或授權權杖。

10. GitHub 登入與 Secret Gist 同步

選擇 GitHub Gist 並主動登入後，本站透過 GitHub OAuth 取得你的公開帳戶 ID、使用者名稱（login）、顯示名稱和頭像網址，用於識別目前同步帳戶和顯示頁尾頭像。頭像網址僅儲存在加密工作階段 Cookie，不進入預設或 JSON 備份；瀏覽器顯示頭像時會向 GitHub 頭像服務發起圖片請求。本站不申請私人電郵、儲存庫、組織或通訊錄權限，不儲存 GitHub 電郵。拒絕授權不影響本機導航與備份功能。

GitHub 的 gist OAuth 範圍可存取帳戶下的 Gist，無法限制至單一應用程式檔案。為定位本站設定，伺服器會讀取你的 Gist 清單中繼資料，並僅讀取和更新由目前帳戶擁有、描述標記為 Baipin Navigation preset sync (v1)、包含 baipin-navigation-presets-v1.json 檔案的 Secret Gist。本站不讀取其他 Gist 的檔案內容，亦不修改無關 Gist。

Secret Gist 不是真正的私有儲存：它不在公開清單展示，但任何知道連結的人均可能讀取內容。預設以未加密 JSON 儲存，可能包含你的書籤、網址、RSS 和偏好；請勿放入密碼、權杖或其他敏感資訊。使用此服務前，登入面板會顯示此限制。

選擇 GitHub 同步時，你要求本站將本機預設傳送給 GitHub，並從該 Gist 讀取預設供你還原。GitHub 按其私隱聲明和條款處理帳戶、請求與 Gist 資料。本站不向 GitHub 傳送你的 Google 身分資料或 Google OAuth 權杖，不會自動讀取 Google Drive 檔案並傳給 GitHub。各服務的工作階段、自動同步開關與版本基線按服務和帳戶分開管理，不按同名帳戶或電郵自動合併；切換後若主動同步，本機目前設定會傳送至新選擇的服務。

GitHub OAuth 使用 state 和 PKCE。帳戶資料及存取權杖（如適用，亦包括更新權杖）經 AES-256-GCM 加密，儲存在獨立的 HttpOnly、Secure、SameSite=Lax Cookie，最長有效期 30 天；存取權杖更新不延長原工作階段期限。GitHub 用戶端密鑰僅儲存在伺服器環境變數 GITHUB_KEY，不會進入前端或匯入匯出。正常請求經 HTTPS 傳輸；伺服器不建立使用者或預設資料庫、不主動記錄原始權杖或完整預設。GitHub 資料不用於廣告、出售、AI 模型訓練或 AI NCII。

登出目前 GitHub 帳戶會清除此裝置的 GitHub 同步工作階段並關閉該帳戶在本裝置的自動同步，不影響獨立的 Google 工作階段，亦不會撤銷 GitHub 授權或刪除 Gist。撤銷權限請在 GitHub Settings → Applications → Authorized OAuth Apps 中撤銷本站應用程式。刪除雲端預設前，先在所有裝置關閉 GitHub 自動同步並登出，再到 gist.github.com 刪除對應的預設 Gist；如再次啟用同步，設定可能重新上傳。Gist 檔案、修訂歷史和備份的保留與刪除以 GitHub 政策為準。

12. 日曆連接、日程讀寫與 iCloud

日曆是可選功能。已有 Google 或 Microsoft 預設同步登入會被識別，但不會因此自動讀取日曆。僅當你點擊日曆授權按鈕並在提供商允許後，本站才追加 Google 的 calendar.calendarlist.readonly（列出日曆）和 calendar.events（讀取、新增、修改和刪除日程），或 Microsoft Graph 的 Calendars.ReadWrite（讀取和寫入日曆及日程）。日曆權限與預設檔案權限不同；你可以拒絕日曆授權並繼續使用其他功能。

本站讀取日曆名稱、標識、可編輯狀態，以及目前月份內的日程標題、起止日期和時間、全日狀態、地點、備註、重複日程標識及版本資訊，用於月曆、日程清單和衝突校驗。點擊儲存會將你填寫的日程寫回所選提供商，點擊並確認刪除會刪除該日程；不自動將日程複製到其他服務。Google、Microsoft 及 iCloud 各可連接一個帳戶，使用者可以選擇顯示其哪些日曆。對組織共用日曆和受限日程，讀寫能力取決於來源服務權限。

iCloud 日曆透過 CalDAV 單獨連接，不使用 Sign in with Apple。你輸入的 iCloud 帳戶和 App 專用密碼只經 HTTPS 傳至本站介面，再用於向 Apple 官方 CalDAV 服務認證。帳戶、App 專用密碼及日曆目錄經 AES-256-GCM 加密後儲存在獨立的 HttpOnly、Secure、SameSite=Lax 工作階段 Cookie 中，最長 30 天；伺服器僅在請求期間解密使用，不另建憑證資料庫，不主動記錄密碼或完整日程。App 專用密碼可能授予 Apple 所允許的日曆存取能力，不能只限於勾選顯示的日曆；請勿輸入 Apple 帳戶主密碼。Apple 按其私隱政策（https://www.apple.com/legal/privacy/）處理帳戶和日曆請求。

載入的日曆及日程內容僅存於目前頁面記憶體，不寫入 localStorage、JSON 預設備份或 Google Drive／GitHub Gist／OneDrive 預設檔案；關閉或重新整理頁面會移除這些記憶體資料。日曆顯示偏好僅儲存各服務的帳戶標識與已選日曆 ID，並隨你主動匯出或同步的預設儲存，用於避免不同帳戶混用顯示選擇。Google／GitHub／Microsoft OAuth 權杖不會進入預設；iCloud App 專用密碼和 Canvas 權杖預設不進入預設，只有你主動啟用下文的獨立密碼加密備份時才以密文加入。頁面可見時日曆每五分鐘更新，亦可手動重新整理。 今天／明天的日曆事件可在本頁以提示條提醒。勾選單一事件的「不再提示」後，瀏覽器會儲存該事件標識的摘要 Cookie（navi_cal_hide_ 前綴），有效期兩天，不含標題、描述或權杖，不納入匯入匯出或多端同步；關閉提示只在目前頁面內抑制重複提醒。事件起止時間改變後視為新的提醒。

14. 日曆登入狀態的預設加密同步

完整預設包含書籤、搜尋引擎、RSS、CITY FEED、背景、語言及天氣／日曆顯示設定。iCloud App 專用密碼及 Canvas 權杖預設由本站伺服器使用環境變數中的統一密鑰進行 AES-256-GCM 加密，密文加入本機預設、JSON 匯出檔案，以及你登入的 Google Drive、GitHub Secret Gist 或 Microsoft OneDrive 預設同步。一般設定不因此全部加密。Google／GitHub／Microsoft OAuth 權杖不納入此備份。

不再要求獨立備份密碼。統一加密密鑰僅儲存在伺服器環境變數中，不寫入瀏覽器或匯出檔案；每次加密使用隨機 nonce，並校驗密文完整性及日曆服務類型。這是伺服器加密，本站伺服器能夠解密還原日曆憑證，不屬於僅使用者持有密鑰的端到端加密。密鑰外洩可能影響所有使用該密鑰的日曆備份；更換或遺失密鑰後，舊密文可能無法還原，需要重新連接日曆。

登入預設同步帳戶後，本站自動讀取相應雲端預設中的加密日曆登入狀態，並為本機尚未連接的 iCloud／Canvas 還原登入；已有連接不會被取代。伺服器只在連接、加密及還原請求期間處理憑證，不另建日曆憑證資料庫。權杖過期或撤銷後須重新連接。登出日曆只結束本機連接；你可在管理介面取消雲端及匯出檔案儲存，確認後自動移除目前同步帳戶雲端及本機預設中的密文，保留其他設定及已連接的日曆。其他帳戶、裝置、舊匯出檔案需分別處理。重新連接日曆將再次啟用預設加密儲存。日程內容及單一事件提醒 Cookie 不進入該備份。舊獨立密碼密文不會自動轉換；已連接的帳戶會重新產生伺服器加密備份，否則需要重新連接。你亦可在登入後的設定中清除目前帳戶的本站雲端預設；清除後自動同步暫停，可選擇重新上傳本機預設、還原本機初始設定或登出本站所有同步及日曆登入。登出不會自動撤銷第三方授權，介面提供相應帳戶的授權管理入口。其他帳戶、裝置及以前匯出的備份不受影響。
